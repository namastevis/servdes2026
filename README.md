# ServDes India Symposium 2026 – Poster voting

Live at https://namastevis.github.io/servdes2026/

- `index.html` – delegates vote for their two favourite posters
- `display.html` – foyer screen slideshow with the voting QR code
- `results.html?key=...` – organiser results

Votes are stored in a Google Sheet via Apps Script. Set `API_URL` in `config.js`.
